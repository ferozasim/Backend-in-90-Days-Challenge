Synchronous → pehle normal code execute hota hai.

Asynchronous → slow/async work ke dauran Node.js doosra work handle kar sakta hai.

Event Loop → async callbacks ko execute karne me help karta hai.

Promise → async result represent karta hai; .then() callback microtask hota hai.

await → async function ko temporarily pause karta hai, Node.js ko nahi.

A callback is a function that is passed as an argument to another function and is called later by that function.
