1 What is node js?
Node.js ek JavaScript runtime environment hai jo Google ke V8 engine par bana hai aur JavaScript ko browser ke bahar, jaise server par execute karne ki capability deta hai

2 What is runtime environment?
Runtime Environment woh software hota hai jo kisi programming language ko execute karne ke liye required APIs aur resources provide karta hai.

3 what is v8 engine?
V8 Engine Google ka high-performance JavaScript engine hai jo JavaScript code ko machine code me convert karta hai taaki wo fast execute ho sake.
